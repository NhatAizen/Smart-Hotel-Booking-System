ENZIUROOMS - CẬP NHẬT LUỒNG ĐẶT PHÒNG VÀ THANH TOÁN
Ngày cập nhật: 06/08/2026

1. Chức năng đã thêm
- Trang xác nhận đặt phòng với họ, tên, email, số điện thoại.
- Tùy chọn "Tôi cũng là người lưu trú"; nhập thông tin khách khác khi bỏ chọn.
- Yêu cầu đặc biệt.
- Thông tin xuất hóa đơn tùy chọn.
- Xác nhận điều khoản và chính sách hủy.
- Hotel Admin cấu hình theo từng loại phòng:
  + Thanh toán tại khách sạn.
  + Đặt cọc online và tỷ lệ cọc (mặc định 30%).
  + Thanh toán toàn bộ online.
- Trang checkout chỉ hiện phương thức được bật cho tất cả phòng đã chọn.
- Backend kiểm tra lại phòng, giá, sức chứa và chính sách thanh toán.
- Booking online được giữ 10 phút bằng trạng thái PENDING_PAYMENT và payment_expires_at.
- VNPay Demo/Sandbox: QR, Internet Banking, ATM, Visa/MasterCard (mô phỏng).
- Hỗ trợ giao dịch DEPOSIT, FULL_PAYMENT, REMAINING_PAYMENT.
- Trang đặt phòng thành công, mã booking và mã check-in dạng ảnh.
- Lịch sử booking và lịch sử payment sử dụng dữ liệu thật từ database.

2. Cập nhật mã nguồn
Giải nén frontend_booking_checkout_full.zip vào:
D:\Smart-Hotel-Booking-System\frontend

Giải nén services_booking_checkout_full.zip vào:
D:\Smart-Hotel-Booking-System\services

Nên sao lưu hoặc commit Git trước khi chép đè.

3. Build backend
Mở PowerShell tại thư mục dự án:

cd D:\Smart-Hotel-Booking-System
docker compose down
docker compose up -d --build hotel-service booking-service payment-service api-gateway

docker compose ps
docker compose logs -f hotel-service booking-service payment-service api-gateway

Flyway tự chạy các migration:
- hotel-service: V20260806.01__add_room_type_payment_policy.sql
- booking-service: V3__add_checkout_payment_and_guest_details.sql
- payment-service: V2__add_payment_type.sql

4. Chạy frontend
cd D:\Smart-Hotel-Booking-System\frontend
npm install
npm run dev

Sau đó nhấn Ctrl + Shift + R trong trình duyệt.

5. Luồng kiểm tra
A. Hotel Admin
- Vào quản lý loại phòng.
- Chỉnh sửa loại phòng.
- Bật ít nhất một phương thức thanh toán.
- Có thể bật cả ba và đặt tỷ lệ cọc 30%.

B. Customer
- Mở chi tiết khách sạn.
- Chọn ngày, khách, số phòng và phòng trống.
- Bấm Đặt ngay/Tiếp tục.
- Nhập thông tin người đặt, khách lưu trú, yêu cầu đặc biệt/hóa đơn.
- Chọn thanh toán tại khách sạn, đặt cọc hoặc thanh toán toàn bộ.
- Với online, dùng màn hình VNPay Demo để mô phỏng thành công/thất bại.
- Kiểm tra Đơn đặt phòng và Thanh toán của tôi.

6. Lưu ý
- Đây là VNPay Demo/Sandbox, không trừ tiền thật.
- Mã QR hiện tại dùng để minh họa luồng demo/check-in; chưa kết nối máy quét QR production.
- Toàn bộ source Java mới của hotel-service, booking-service và payment-service đã biên dịch thành công bằng javac Java 17.
- Frontend đã lint riêng các file mới thành công và Vite transform 1903 module thành công. Build trong môi trường đóng gói dừng ở bước minify vì thiếu binary Linux lightningcss; trên Windows sau npm install sẽ tải binary phù hợp.
